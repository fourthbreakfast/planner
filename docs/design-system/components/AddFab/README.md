The round button that adds an event: a `fab` wide circle filled with `ink`, with a plus drawn in the `page` colour at `stroke-thick`, `icon` across. It floats at the bottom right, `space-4` from the edges and clear of the system bar, over the list.

The list ends with an `end-row` of empty space so the button never covers the last event. It does not move when the list scrolls.

The consumer provides what a touch does (open the empty event form). Describe it to screen readers as "add an event".

- Do keep it the only filled shape on the screen besides the check box.
- Don't use a priority colour, a shadow or a label.
