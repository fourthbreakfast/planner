The button that adds an event: a plain plus drawn like the other icons, `icon` across with `stroke-thin` lines in `quiet`, inside a `touch` square. It sits at the bottom right, clear of the system bar, over the list.

It has no fill, no ring and no shadow, because nothing else on the screen is filled. The list ends with an `end-row` of empty space so the plus never covers the last event.

The consumer provides what a touch does (open the empty event form). Describe it to screen readers as "add an event".

- Do keep it as quiet as the bin.
- Don't make it bigger than a touch square, and don't fill it with `ink` or a priority colour.
