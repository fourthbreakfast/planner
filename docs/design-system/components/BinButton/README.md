The way into the bin: a 20px line drawing of a can with a lid and handle, in `quiet`, with the number of things inside in `note` beside it when there are any.

It is the right-most control in the title bar. One touch opens the bin; the bin screen uses the same title bar with a back arrow in this spot.

The consumer provides the number of binned things.

- Do hide the number when the bin is empty.
- Don't tint the icon red or fill it.
