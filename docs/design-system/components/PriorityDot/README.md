Priority is a restrained circular mark: high 8dp, medium 7dp, low 6dp, and an 8dp outline ring for none. The size difference supplements red/yellow/green color. Accessible labels name the actual priority; color alone does not explain an action.

The dark theme uses the P21 reference accents. Supported light surfaces use darker variants to retain contrast. Essential outlines use control-outline, not the quieter structural divider token. Do not use priority colors for ordinary body text or broad row backgrounds.

An interactive priority control has a 48dp target, quiet hover/press feedback, a visible keyboard-focus outline, and the existing none/low/medium/high cycle. Priority only ranks a task among its siblings; a high-priority child stays inside its parent. A shortlist marker shown beside priority must use a distinct shape, not an indistinguishable second dot.
