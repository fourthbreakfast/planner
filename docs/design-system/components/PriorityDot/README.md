The priority marker: a small filled circle in `priority-high`, `priority-medium` or `priority-low`, or an outline ring in `quiet` for none.

Draw it `dot` across and place it in a `dot-lane` by `touch`, so a thumb can change it. Touching it moves to the next level: none, low, medium, high, none. Read the level out loud for screen readers ("high priority"), because color alone is not enough.

The consumer provides the level and what happens on a touch. A priority only ranks a task among its siblings, in priority mode: a high subtask goes to the top of its parent's subtasks, never above its parent.

- Do keep every dot the same size.
- Don't use the three colors for text or backgrounds.
