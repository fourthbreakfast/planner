The event form presents name, day, time, reminder (for timed events), location and notes. The day summary includes its date range and recurrence. Touching day opens a calendar with the event end date, repeat schedule and repeat end date together. Its changes apply on set; cancel keeps the prior values. End dates before the start day prevent confirmation and show an explanation. Dates can be cleared.

Time sits directly below day and keeps the established all-day/start/start-and-end choices. Reminders offer useful presets and a custom positive whole number of minutes, hours or days before the event. Invalid or overflowing values cannot be applied. Presets apply immediately; custom values use an explicit set action.

Chooser panels scroll, respect the on-screen keyboard and are capped at 560dp on large screens. Save and recurring-event occurrence/series confirmation retain their established behavior.
