Three equal phone tabs run along the top: `tasks`, `agenda`, `notes`. Labels use IBM Plex Sans. The selected tab uses teal `accent` and a short underline, providing a shape signal as well as color. Tabs expose their role and selected state to accessibility services.

A touch switches tabs; holding a tab opens settings. Ordinary horizontal sweeps move to neighboring tabs and stop at the ends. Sweeps starting at the screen edge belong to the system back gesture. Row swipes and dragging require a hold first.

Counts and controls live in the bar below. Windows uses three simultaneous columns rather than this tab bar. Screen and editor headings use the shared sans-serif title style.
