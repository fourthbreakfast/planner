The one control that switches how the list is ordered: a plain 10px circle in a `touch` square. Grey (`quiet`) is tree mode, where tasks stay as placed and can be dragged. Red (`priority-high`) is priority mode, where each level of the list is ranked by priority and dragging is off.

Place it at the top right, just left of the bin. Describe it to screen readers as "priority mode" with an on/off state.

The consumer provides whether priority mode is on and what happens on a change.

- Do show only the dot; the color is the whole message.
- Don't add a label, a second icon or a ring.
