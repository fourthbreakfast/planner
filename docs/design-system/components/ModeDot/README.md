The one control that switches how the list is ordered: a plain 10px circle in a `touch` square. Grey (`quiet`) is tree mode, where tasks stay as placed. Red (`priority-high`) is priority mode, where each level of the list is ranked by priority. Tasks can be dragged in both. Switching jumps to the top of the list and leaves everything open or closed as it was.

Place it at the top right, just left of the bin. Describe it to screen readers as "priority mode" with an on/off state.

The consumer provides whether priority mode is on and what happens on a change.

- Do show only the dot; the color is the whole message.
- Don't add a label, a second icon or a ring.
