# Planner project guidance

For interface, visual, copy or brand work, read `docs/design-system/README.md` first. It is the current P21-based design reference. Follow approved decisions; distinguish proposed specifications and open decisions from approved rules.

Reuse shared patterns and semantic tokens. Document a new design pattern and its decision status in the design system instead of silently creating a conflicting per-screen style. Routine work within an approved rule does not need renewed approval.

The token JSON mirrors the 2.0 runtime. The pre-P21 document and component HTML previews are historical references. Preserve existing functionality during visual work. The generated P21/P24 images establish direction; explicit written decisions override image artifacts.
